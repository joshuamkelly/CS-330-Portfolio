# CS-330-Portfolio

This repository contains my work for CS-330 Computational Graphics and Visualization.

## Module Eight Reflection

### How do I approach designing software?
Working on the 3D scene helped me develop better design skills and get better at planning. I started by analyzing the reference image to identify primitives that could be used to recreate all objects on that image. From there, I focused on placement, proportions, textures, and lighting. This approach allowed me to think about the scene in smaller, technical parts rather than trying to write the code for something large-scale right away. I improved in breaking down complex concepts and visualizing a project before starting to code. I can use this strategy in future projects when I am faced with creating something similar to the project done for Milestone 5.

### How do I approach developing programs?
While working on this project, I gained valuable experience in program development and iterations. For Milestones 1-4, I approached programming through the method of trial-and-error - I tried some code and saw whether it helped me achieve certain objectives. In Milestone 5, however, things changed. As I had to build a complex program from scratch, and even small mistakes with transformations, textures, lighting, and camera settings would lead to noticeable consequences, I had to change my approach and focus on incremental changes. In this case, I relied on using modular functions and implementing only certain features of the scene per milestone, as I wanted to test my results each time.

### How can computer science help me in reaching my goals?
Computational graphics and visualization provided me with hands-on knowledge and practice in several important areas, including C++, program structuring, transformations, textures, lighting, user interactions, etc. This project helped me gain more confidence in my abilities to work on large projects in a structured way and solve various problems. On a professional level, this experience is invaluable as it demonstrates the ability to solve problems, debug issues, implement modular programs, and build a working product step-by-step. Moreover, although I might never work with computer graphics, these skills will definitely prove useful in software engineering.
